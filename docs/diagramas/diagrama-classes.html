Sistema de Informação Hospitalar — Diagrama de Classes

PUC Minas · Engenharia de Software · Programação Modular — Trabalho Prático

1. Modelo de domínio

Triângulo vazado = herança · losango cheio = composição · losango vazado = agregação · linha tracejada = dependência

2. Arquitetura em camadas

Controller → Service → Repository → Model, com DTOs, mappers e validadores de regra de negócio

3. Hierarquia de exceções

Todas as exceções de negócio derivam de HospitalException e são convertidas em ErroResponse pelo GlobalExceptionHandler
