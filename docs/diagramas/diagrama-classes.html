Vitalis — Diagrama de Classes

PUC Minas · Engenharia de Software · Programação Modular — Sprint 2

1. Modelo de domínio

Triângulo vazado = herança · losango cheio = composição · losango vazado = agregação · linha tracejada = dependência ou realização de interface

2. Situação da consulta

Seis estados. CONCLUIDA, CANCELADA e NAO_COMPARECEU são finais — para reatender, agenda-se uma consulta nova

3. Ciclo do procedimento cirúrgico

Não existe transição de AGENDADO para CONCLUIDO: o enunciado proíbe concluir o que não foi iniciado

4. Arquitetura em camadas

Controller → Service → Repository → Model, com DTOs, mappers e validadores de regra de negócio

5. Hierarquia de exceções

Todas as exceções de negócio derivam de HospitalException e viram ErroResponse no GlobalExceptionHandler
